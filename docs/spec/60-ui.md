# 60 · 界面规格

技术栈：**shadcn/ui（Base UI 原语）+ Tailwind v4 + lucide-react + sonner**；组件以源码进 `packages/client/ui/src/components/ui/`（copy-in，不是依赖）。

## 6.1 创作页（三栏）

```
┌───────────┬──────────────────────────────┬──────────────┐
│ 文档树     │ 文档（主位）                  │ 创作会话      │
│ clamp 树宽 │ flex（铺满剩余）              │ 视口 28%      │
│ 可隐藏 ⌘B  │ 预览 ⇄ 编辑                    │ 可收起 ⌘J     │
└───────────┴──────────────────────────────┴──────────────┘
   6px 拖拽把手        6px 拖拽把手
```

| 行为 | 规格 |
|---|---|
| 默认宽 | 树 `clamp(220px, 17vw, 320px)` / 聊天 `视口 × 28%`；中间铺满剩余宽度，不设 `max-width` |
| 钳制 | 树随屏宽（窄屏转抽屉）；聊天 300–960px 且 ≤ 视口 50% |
| 拖拽 | 6px 把手，hover 高亮，`col-resize`；**双击复位默认** |
| 隐藏左树 | 树头部 `⟨`；隐藏后文档区铺满，左上浮标「⟩ 文档树」召回 |
| 收起消息流 | 手动（完成后只标「已完成 · 可收起」）；收成 46px 窄条，把手同时消失 |
| 持久化 | `localStorage: {treeW, chatW, treeHidden, chatCollapsed}`，刷新恢复；召回时用记忆宽度 |
| 快捷键 | `⌘B` 切树、`⌘J` 切消息流（Ctrl 同）；输入框聚焦时仍生效 |
| 窄屏 | <768px 文档树为覆盖式抽屉；<1024px 创作会话为覆盖式抽屉（默认收起，右下浮标召回） |

**文档区顶部**：面包屑 `分组 / 文档` · 类型徽标 · 「版本」「编辑原文」「编辑类型」（三枚 `ghost` 按钮：**左图标 + 右文案、无边框**，同高同内距，与版本按钮对齐） · 「⎇ N 个版本」。
**文档区主体**：默认**预览**（streamdown 渲染，含 mermaid）。点「编辑原文」进入**独占编辑态**：正文原地切成 textarea，顶栏只留「取消」「保存」（隐藏返回、版本、编辑类型、会话）；`⌘/Ctrl+S` 等同保存，保存成功才退出；「取消」丢弃草稿回到预览（有未保存修改时先确认），有未保存修改时拦截刷新/关闭。保存只写 `MAIN.md`（刷新 `updatedAt`），**不做 git 提交、不推送**。`/docs` 列表页只读（不提供正文编辑）：右栏只留一枚「编辑」（`outline`，**左图标 + 右文案**）跳创作页；「类型编辑 ↗」不在右栏，仅右键菜单保留，带 `?doc=` 跳类型页，返回时直达该文档。AI 修改后自动刷新并标记「AI 修改 N 处 · 未提交」。
**回到顶部**：预览状态下正文纵向滑出 320px 后，正文右下角浮出圆形 `outline` 图标按钮（`ArrowUp`，40px，`aria-label="回到顶部"`，指针为 `pointer`）；点击平滑滚回顶部（系统「减弱动态效果」时瞬时），回到阈值以内即隐藏。悬停或键盘聚焦时按钮上浮、箭头自上滑出并由下方补位（「返回」动效），左侧展开「回到顶部」标题；触屏无 hover，保持纯图标。窄屏上移避开右下角「创作会话」浮标；「编辑原文」态不出现。
**选区上下文**：预览与「编辑原文」都支持选中区域 → 右键「加入对话上下文」→ 累积进上下文缓存（顶栏与输入框上方显示处数/字数，可单个移除或清空）→ 随下一条消息发送，成功后立即清空；预览里右键图片（Archify 海报或普通图片）提供「复制图片」（写系统剪贴板为 PNG，SVG 自动栅格化）与「加入对话上下文」，后者加入的是该图的 Markdown 引用；没有选区、也没点中图片时保留浏览器原生右键菜单。
**技能指令（/）**：输入框首字符输入 `/` 时在输入框上方弹出技能浮层（`listbox`），只列出**当前文档类型 `type.yaml` 勾选**、且全局启用 / frontmatter 合格的技能：名称（等宽）+ 一行截断的描述 + 来源徽标（个人/项目），标题栏显示命中数与「输入筛选」。继续输入按名称/描述过滤，名称命中排在描述命中之前；`↑↓` 移动、`↵`/`Tab` 插入、`Esc` 关闭，点击条目同样插入且保持输入框焦点。选中后写回 `/skill:名称 `（光标落到末尾），随消息发送；服务端把该技能的 `SKILL.md` 正文（去掉 frontmatter）包成与 pi 相同的 `<skill name location>` 块放在提示词最前，用户消息仍原样显示命令。也认手输的 `/技能名 …` 简写（只有命中「类型勾选 + 可用」的技能才当命令，`/tmp/foo` 这类普通文本不受影响）。类型未勾选的技能既不出现在列表里，手输 `/skill:名称` 也会被拒绝（提示去「编辑类型 → 技能」勾选）；技能不存在/已停用/不合格时同样发送失败并在消息流提示原因。列表为空时提示去「编辑类型 → 技能」或「设置 → Skills」添加并启用。

**消息块**（密度已定）
- 文本：streamdown 流式；thinking 实时显示为限高可滚动的「思考」块；工具卡合并（`read · path` / `edit · MAIN.md +18 −2`）；附件 chips；选区块。
- **生图结果**：工具结束后在同一条消息里追加 `images` 块；多图拼格子（单图大图），点击打开页面级放大遮罩（Esc/点背景关闭、可新标签打开），右键菜单「复制图片 / 加入对话上下文 / 查看大图 / 复制 Markdown 引用」；加入上下文复用图片 Markdown 引用的选区缓存。
- **刷新回放精简**：只保留用户消息、每轮最终回复、已答复澄清卡、带生图结果的消息；普通工具卡/思考/中间文本只在实时过程中展示（生成中/等待中刷新例外，保留当前轮过程）。

**生成中暂停**：会话状态为「创作中」或「等待输入」时，输入框右下角在「发送」左侧出现 `outline` 的「暂停」按钮（`Square` 图标 + 文案，`aria-label="暂停本轮创作"`）。点击后 `POST .../abort?session=<id>`，立即中断模型流与工具；已写入 `MAIN.md` / `assets/` 的内容保留，等待中的澄清卡切成「已失效」，状态回到「待命」并在消息流末尾提示「已暂停本轮创作」。请求进行中按钮显示「暂停中…」并禁用；空闲/已完成/出错时不出现。暂停只作用于当前会话，其他会话继续跑。

**会话列表（多会话）**：创作会话头部在文档图标左侧有「会话」图标（`MessagesSquare`，`size="icon"`，`aria-haspopup="dialog"`）。点开是标题栏下方的轻量浮层：顶部「会话 N · 上下文互相独立」，中间按最近使用倒序列出会话（当前项勾选 + 浅底；非当前项用状态点区分空闲/创作中/等待输入/出错，右侧显示时分或月-日），底部「＋ 新建会话」整行 `ghost` 按钮。点会话即切换：消息流清空后按新 id 重连 SSE，文件视图会自动退回会话；服务端记 `activeId`。新建会立刻切到「新会话」，发第一条消息后标题自动变成消息摘要。浮层点外面或 Esc 关闭；空清单/加载失败时给错误文案与「重试」。

**文档文件夹（只读）**：创作会话头部「收起」左侧有文档图标（`Files`）。点开后消息流与输入框整体替换为 `docs/<group>/<name>` 的文件树；再点图标返回会话，消息滚动位置与输入草稿保留。树递归展示全部可见内容（`MAIN.md`、`meta.yaml`、`assets/`、`research/`、`sessions/` 等），隐藏 `.` 开头项与 `.DS_Store`，不跟随符号链接；文件夹可展开/折叠，文件行显示大小。点文件进入详情：Markdown 渲染、普通文本只读、图片内联、其他格式下载；支持返回树、刷新、复制相对路径、新标签打开/下载。目录超过扫描上限、文本超过 256KB 时提示截断；路径穿越/隐藏路径/符号链接由 API 拒绝（400），不存在返回 404。取数走 `/api/docs/<group>/<name>/files`、`/files/content`、`/files/raw`，不写盘、不产生 git 提交。

## 6.2 类型编辑器（两列）

```
┌──────────────────┬────────────────────────────┐
│ 配置 clamp 列宽    │ 编辑器（铺满剩余）            │
│ 名称/描述/锁定模型  │ [提示词 | 注入预览]          │
│ 技能（平铺勾选）    │ textarea / 预览面板          │
│ MCP （平铺勾选）    │                             │
│ 资源文件卡 + 管理器 │ 底部：影响 N 会话 · 下一轮生效 │
└──────────────────┴────────────────────────────┘
```

- 两列在 <1024px 堆叠：配置区限高滚动，编辑器占满剩余高度；≥1024px 配置列 `clamp(300px, 22vw, 400px)`、编辑器铺满剩余宽度。
- **技能/MCP 平铺 checkbox**（每项标「全局」来源），不做弹层多选。
- **注入预览是 tab**，与提示词二选一；展示拼好的系统提示词开头（含 skills 段说明）。
- **文件管理器**：按钮弹悬浮对话框 → 文件**树**（缩进 + 引导线 + 展开箭头 + 文件夹/文件图标）；拖拽文件到文件夹移动；新建文件夹 / 上传 / 重命名 / 删除 / 复制相对路径；行内**图标按钮 + hover tooltip**。
- 顶部：`复制类型` / `删除` / `回到创作` / `保存`；未保存离开提醒。
- **不放**类型列表与切换下拉——类型管理只在设置页（新建/复制/删除），进入编辑器时已确定类型。

## 6.2.1 澄清选择卡（聊天内）

AI 调用 `request_clarification` 时，聊天里出现一张浅琥珀色卡片：

- 顶部「需要澄清」徽标 + 「选完 AI 会继续写，不会另起一轮」；`intro` 一句话。
- 1–3 道题，每题 2–4 个**短选项**（label ≤12 字，解释放 description）+「其他…」自由输入。
- 全部选完才启用「提交选择」；另有「跳过，按默认写」，把空项记为「未指定（按最合理判断）」。
- 提交/跳过后卡片切成「已答复 · AI 继续创作」并列出每题答案；超时/中断切成「已失效」。
- 等待期间会话状态「等待输入」，主输入框禁用并提示「AI 正在等你澄清，请在上方选择」。
- 卡片与答案写进该会话的 `<id>.ui.jsonl`，刷新/重连后按 `mergeKey` 回放。
- **未提交的选择做本地草稿**（localStorage，按 groupId）：刷新后恢复选项/其他输入；提交或失效后清除。已提交的决策由 answered 快照保留，刷新后仍可见。

## 6.3 Git 抽屉

右侧 Sheet：commit 时间线（sha 短码 · 时间 · `ai|human` 徽标 · 摘要 · 变更文件数）；点开看 diff（逐文件、吸顶文件头、二进制提示）；每项「回滚到此处」。

## 6.4 设置页

竖向 Tabs（供应商 / 存储 / 类型 / MCP / Skills），表格 + 右滑详情抽屉；模式与参考仓库一致（见 50-settings）。页面**不设最大宽度**：内容铺满视口，左栏 `clamp(180px, 15vw, 260px)`；<768px 时左栏转为顶部横向可滚动 Tabs，表格容器横向滚动，不压扁列。分区写在 URL hash 上（如 `/settings#types`）：点击 tab 即写回地址，刷新、收藏、分享都停在当前分区，默认分区不写 hash；既有 `/settings#types` 深链照旧直达（类型编辑器删除后回跳）。

## 6.6 主题

- 亮/暗两套（`next-themes`），CSS 变量；写作语气：中性灰 + 单一强调色，弱边框、少阴影。
- 字号：正文 15px/1.75（文档区）、界面 13.5px；宽屏下正文用 `clamp()` 微增至 18px；中文优先 `PingFang SC` 回退。

## 6.8 全屏与自适应（全局约束）

- **不设页面级 `max-width`**：`/`、`/docs`、`/settings`、`/types/*`、`/workspace/*` 的主内容区铺满视口，左右留白只由响应式内边距决定。
- **高度**：全屏页用 `h-dvh`（而非 `h-screen`），移动端浏览器工具栏伸缩不裁切；页面内滚动区各自 `min-h-0 overflow-auto`。
- **断点**：`<768px` 单列/抽屉；`768–1023px` 双列；`≥1024px` 三栏创作页；`≥1536px` 内容继续拉伸，不出现居中窄栏。
- **流体尺寸**：侧栏/聊天栏用 `clamp()` + 视口百分比；文档正文用 `clamp()` 在 14–18px 间随屏宽变化。
- **溢出**：长路径、长 URL、代码块可换行或横向滚动；表格容器 `overflow-x-auto` 且给最小列宽，避免窄屏挤压。
- **弹窗/抽屉**：宽度用 `min(px, 视口百分比)`，窄屏贴边，宽屏不铺满全屏。

## 6.9 Archify 结构编辑器（全屏 overlay）

**入口**：`/workspace` 预览右键 Archify 海报 →「打开交互图示」或「编辑结构」；`/docs` 只读页点击 Archify 海报 → 新标签打开同一张图的交互图示。普通 SVG/图片不提供结构编辑，右键提供「复制图片 / 复制路径」。

```
┌──────────────────────────────────────────────────────────────┐
│ 关闭  Archify 图示  architecture  ●未保存  撤销 重做 校验 保存│
├──────────────────────────────┬───────────────────────────────┤
│ 结构 | JSON                  │ 实时交互预览（sandbox iframe） │
│ 组件/步骤/参与者表           │ 编辑后 600ms 自动更新          │
│ 关系/消息/迁移表             │ 点击节点 → 选中左侧行          │
│ 标题/预设/动画/质量          │ 左侧选行 → focus 节点          │
└──────────────────────────────┴───────────────────────────────┘
```

- 结构表按类型配置字段；architecture 额外 pos/size；workflow lane/col；sequence message y；dataflow stage/row。
- 高级字段（boundaries/cards/phases/segments/activations/layout）不在表格里展示，但原 IR 原样保留；JSON tab 可编辑全部。
- 编辑结构/JSON/预设后，600ms 防抖请求 `/archify-preview`；右侧 viewer 实时更新，不写源。
- 校验按钮只校验；保存成功才替换海报/viewer；诊断按 subject.path 标红行；预览失败保留 last-good。
- 撤销/重做 40 步；Cmd/Ctrl+S；关闭确认；409 重新加载/覆盖。
- v1 不做像素拖拽；位置用字段精确调整。
